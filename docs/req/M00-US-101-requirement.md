# M00-US-101 需求錨點

> US: M00-US-101 | 建立: 2026-11-01 | 來源: 對話摘要（dav-planner Step 1-3 需求訪談）

## 用戶原話（唯讀）

- R1: 「1. 我想有一個手機APP，他會好像Wechat 一樣，他可以錄我的語音訊息，也可以讓我輸入文字內容(如果Agent 能回覆我語言訊息更皆)。」
- R2: 「3. 我想APP既可用在手機，也可以用在macos APP」
- R3: 「Voice Agent 應該會有不同的session ?」
- R4: 「自動分流 ＋ 開新對話按鈕（推薦）」
- R5: 「APP 對話輸入或新Agent 訊息發出後的動作，應該如下：1. 如果用戶已經在對話流的最底部時，新訊息到了後就要滾動到最底, 目的是看到最新訊息； 2. 如果用戶是拖拉到上方的觀看緊上方的歷史訊息，新訊息到了後，在下方就要有一個"新訊息button提示"，用戶按了button 之後，滾動到最下方看最新訊息」

## 澄清後驗收句

- R1: 介面要似 WeChat：自己同 Agent 嘅訊息一來一回。
- R2: 同一個 App 要喺手機同 macOS 都行得。
- R3: 對話應該分多條 session（唔係一條打天下）。
- R4: session 由 Agent 自動分流（同一話題就續舊對話），用戶只喺想新開時撳一下。
- R5: 新訊息到達時：在底部就自動滾到底；唔喺底部就出「新訊息」按鈕，撳咗先滾落去。
