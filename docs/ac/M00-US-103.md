## Given-When-Then

- **AC-1**: Given macOS App 啟動 When sidecar spawn Node/Bun process 並載入 `@earendil-works/pi-coding-agent` Then 建立 `createAgentSession()`（cwd = 用戶指定 workspace），App 顯示「Agent 已就緒」
- **AC-2**: Given 一段 prompt When 經 IPC 交畀 sidecar Then 收到 streaming text delta 並即時轉發去 backend
- **AC-3**: Given App 退出 / Mac 睡眠 When sidecar 收到 SIGTERM Then 正常 `session.dispose()`，唔留孤兒 process
- **AC-4**: Given sidecar 崩潰 When supervisor 偵測到 Then 自動重啟（≤ 5 秒）並喺 App 顯示「Agent 已重啟」
