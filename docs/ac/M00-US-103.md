- 類型: US ｜ 階段: ① 語音對話 loop ｜ 優先級: P0 ｜ Story Point: 8
- 驗收方式: 跑 `REGRESSION_MODULE=M00 ./run_pipeline.sh M00-US-103`

## Given-When-Then

- **AC-1**: Given macOS App 啟動 When sidecar spawn Node/Bun process 並載入 `@earendil-works/pi-coding-agent` Then 建立 `createAgentSession()`（cwd = 用戶指定 workspace），App 顯示「Agent 已就緒」
- **AC-2**: Given 一段 prompt When 經 IPC 交畀 sidecar Then 收到 streaming text delta 並即時轉發去 backend
- **AC-3**: Given App 退出 / Mac 睡眠 When sidecar 收到 SIGTERM Then 正常 `session.dispose()`，唔留孤兒 process
- **AC-4**: Given sidecar 崩潰 When supervisor 偵測到 Then 自動重啟（≤ 5 秒）並喺 App 顯示「Agent 已重啟」
- **AC-5**: Given 用戶發一句新訊息 When Agent 判斷話題 Then 同一話題續返原本 session；新話題開新 session 並自動命名（用戶唔使理）
- **AC-6**: Given 用戶想「帶住舊上文開新」 When 呼叫 fork 入口 Then 由現有 session 分岔出新 session，原本 session 唔受影響

## Definition of Done（技術視角）

- [ ] 探針 `M00-US-103-sidecar-session-lifecycle` 必通過
- [ ] dispose 後 `ps` 檢查無殘留 process

## 業務規則

session 由 sidecar 用 file-backed SessionManager 持久化喺 Mac 本地（唔上傳雲端）；workspace 由用戶指定（預設 `~/agent-workspace`）；session 屬於一個 workspace（切 workspace = 換一組 session）；session 分流規則：同一話題續舊、新話題開新並自動命名；fork（帶上文開新）只係第二入口、預設唔開

## 依賴

Pi SDK（Node ≥ 20 或 Bun）、Tauri sidecar 機制（`newSession` / `switchSession` / `fork`）
