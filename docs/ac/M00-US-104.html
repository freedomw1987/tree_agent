驗收方式：跑 `REGRESSION_MODULE=M00 ./run_pipeline.sh M00-US-104`

Given-When-Then

  1. Given App 有有效 token When 發送訊息（帶 `request_id`）Then Lambda 驗證 token → 訊息入 DynamoDB → relay 派發畀 Mac sidecar；App 收到 ack（≤ 2 秒）
  2. Given 同一 `request_id` 因網絡重試送兩次 When 處理 Then 只執行一次（冪等），App 只見一條訊息
  3. Given sidecar 完成任務 When 結果回傳 Then 寫入 DynamoDB（user_id / request_id / role / content / ts），App 拉 transcript 時見到
  4. Given App 網絡中斷 When 恢復 Then 自動重連並補拉漏咗嘅訊息（唔漏訊息、唔重複顯示）
  5. Given 無效 / 過期 token When 呼叫 API Then 回 401 + App 顯示「請重新登入」（唔係 5xx）

Definition of Done

  • 探針 `M00-US-104-relay-idempotent-and-persisted` 必通過

業務規則

transcript 存 DynamoDB（partition key = user_id）；每則訊息有 `request_id`（UUID）做冪等鍵；token 唔可以出現喺任何 log
