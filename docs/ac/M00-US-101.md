## Given-When-Then

- **AC-1**: Given App（iOS / Android / macOS 任一）When 打開 Then 見到 WeChat 式對話介面（自己訊息靠右、Agent 訊息靠左、輸入列、錄音鍵、時間戳）
- **AC-2**: Given 已有對話紀錄 When 重新打開 App Then 見到上次 transcript（由 backend 拉，唔係本機 hardcode）
- **AC-3**: Given 手機端同 macOS 端用同一帳戶 When 各自拉 transcript Then 兩邊見到同一份對話
- **AC-4**: Given 輸入列有文字 When 撳「發送」Then 訊息即時出現在對話串並顯示「已送出」狀態（等 backend ack）
- **AC-5**: Given 手機端對話畫面 When 撳對話標題 chip / 「開新對話」Then 見到 session 抽屜（列出所有對話、標明當前、可切換）；開新後當前 session 即時切換，舊對話保留
- **AC-6**: Given 當前 session 同其他 session 都有訊息 When 喺當前 session 睇到跨 session 訊息 Then 該訊息標明所屬對話（唔會睇唔出邊段對話）
- **AC-7**: Given 用戶已喺對話流最底部 When 新訊息（用戶或 Agent）到達 Then 自動滾動到最底，直接見到最新訊息
- **AC-8**: Given 用戶已拖拉到上方睇緊歷史訊息 When 新訊息到達 Then 唔自動搶走佢嘅閱讀位置，底部出現「新訊息」按鈕；撳咗按鈕先滾到最下方

## 業務規則

App 層只負責 view + 呼叫 API，唔准包含任何 Agent 邏輯；介面語言預設繁中；對話 session 由 Agent 自動分流，App 只提供入口（session 抽屜 ＋ 開新對話）；黏底規則：在底部 → 新訊息到達自動滾到底；唔喺底部 → 唔搶位置，出「新訊息」按鈕，撳咗先滾落去（距底 ≤ 80px 當作「喺底部」）
