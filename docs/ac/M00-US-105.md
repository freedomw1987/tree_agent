## Given-When-Then

- **AC-1**: Given Agent 回覆文字 When 用戶撳「播報」或開咗自動播報 Then backend 用 Polly 合成 mp3（粵語 voice）並回傳 URL，App 播放
- **AC-2**: Given 同一段文字 When 連續撳兩次播報 Then 只請求一次 TTS（結果有 cache）
- **AC-3**: Given TTS 失敗 When 發生 Then 文字回覆照常顯示，App 顯示「語音暫時播唔到」，唔影響任務結果
- **AC-4**: Given App 喺背景 When 播報 Then 唔硬彈前景（背景播報由 US-131 嘅 push 機制負責）

## 實測結論

**本地 TTS 已完成**（plugins/tauri-plugin-ios-tts/）：AVSpeechSynthesizer，粵語 voice 優先（yue-HK → zh-HK → zh-TW → en-US），音訊階段 .playback + .spokenAudio（靜音掣都出聲，符合「走路時聽」）。App 端：每條 Agent 回覆有「讀出嚟」掣 ＋ 設定可開「自動讀出」；command：tts_speak / tts_stop / tts_status。**未做**：**AWS Polly 路徑**（Hiujin 粵語，聲質好啲但要經 relay 傳 mp3 落手機播 —— 等推播憑證同音訊方案一齊做）

## 業務規則

TTS 一律用 AWS Polly voice `Hiujin`（yue-CN，**engine 必須 neural**）；格式 mp3（通知附件唔用 opus，iOS 支援唔穩）；App 內播報只讀前 150 字；通知版 ≤ 30 字摘要；mp3 存 S3 ＋ URL 交付；cache 24 小時；長回覆（> 800 字）只播前段並提示「全文睇螢幕」

## 依賴
